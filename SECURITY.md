# Security reports

Please use GitHub's private vulnerability reporting option in the repository's **Security** tab when available. Include the affected version, reproduction steps, and impact. Do not post exploit details, credentials, private recordings, or personal images in a public issue. If private reporting is unavailable, contact the maintainer through the GitHub profile first to arrange a private channel.

General bugs and feature requests can use public Issues. Security reports about third-party components should also be sent to their upstream maintainers when appropriate.

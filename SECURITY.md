# Security reports

Please use the enabled **Report a vulnerability** option under this repository's **Security → Advisories** page. Include the affected version, reproduction steps, and impact. Do not post exploit details, credentials, private recordings, or personal images in a public issue. If that private channel is temporarily unavailable, contact the maintainer through the GitHub profile first to arrange another private channel.

General bugs and feature requests can use public Issues. Security reports about third-party components should also be sent to their upstream maintainers when appropriate.

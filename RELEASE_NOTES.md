# GestureScreen v1.0.0

First public release of the completed STM32F429 gesture reader and Gesture
Studio capture tool.

## Downloads

- `GestureStudio.exe`: self-contained Windows x64 application. Windows 11 was
  tested. Windows 10 is a support target without a physical-machine test.
- Firmware HEX, matching AXF/map, and final/research checkpoints are in the
  repository. Source archives are generated by GitHub for this tag.

## Included

- Reader firmware source, CubeMX `.ioc`, Keil target, and USB/Ethernet capture
  paths for the EmbedFire Challenger V1.
- Six-class deployed supervised model, separate research checkpoint, and model
  conversion/training tools.
- Gesture Studio source, local recording and review UI, build configuration,
  dependency list, and third-party license inventory.

## Accuracy and limits

Correction to the original publication: the final deployed six-class model was
trained with hard labels only, without teacher outputs or distillation. The
historical `student` checkpoint filename does not imply distillation. The
frozen int8 TFLite model scores **293/361 (81.16%)** on the private validation
split and **294/350 (84.00%)** on the private test split in offline top-1
classification using the bundled RGB565 preprocessing and LiteRT 2.2.0.
These numbers are not on-board or universal-user accuracy. Some small or
ambiguous gestures may lower dataset scores; real-use accuracy was not
systematically measured. The 100 ms board inference goal remains unmet. No
new hardware or Windows 10 test was performed for the public release.

## Privacy

The dataset was recorded by the owner and contains personal imagery. It is
**not published**. Neither the repository nor release assets include raw
camera frames, recording sessions, sample images, or dataset annotations.

# GestureScreen v1.0.0

First public release of the completed STM32F429 gesture reader and Gesture
Studio capture tool.

## Downloads

- `GestureStudio.exe`: self-contained Windows x64 application. Windows 11 was
  tested. Windows 10 is a support target without a physical-machine test.
- Firmware HEX, matching AXF/map, and student/teacher checkpoints are in the
  repository. Source archives are generated by GitHub for this tag.

## Included

- Reader firmware source, CubeMX `.ioc`, Keil target, and USB/Ethernet capture
  paths for the EmbedFire Challenger V1.
- Six-class deployed student model, retained teacher checkpoint, and model
  conversion/training tools.
- Gesture Studio source, local recording and review UI, build configuration,
  dependency list, and third-party license inventory.

## Accuracy and limits

The best student validation run was 292/361 (80.89%); the three-seed mean was
77.65%. The teacher scored 336/361 (93.07%) and was not deployed. These are
private validation measurements, not on-board or universal-user accuracy. The
100 ms board inference goal remains unmet. No new hardware or Windows 10
test was performed for the public release.

## Privacy

The dataset was recorded by the owner and contains personal imagery. It is
**not published**. Neither the repository nor release assets include raw
camera frames, recording sessions, sample images, or dataset annotations.
